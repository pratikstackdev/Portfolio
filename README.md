# Pratik Srivastava — Editorial Developer Portfolio

A responsive React + TypeScript portfolio with a cinematic black-and-amber editorial visual system, a transparent portrait, interactive particle globe, ripple field in the About section, enhanced project showcases, and skill cards.

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Personal details

The portfolio content is based on the supplied profile information. Project descriptions are intentionally framed as concepts/explorations where verified outcomes were not supplied. Replace the GitHub placeholder with the correct profile URL when available.
